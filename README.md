## Bahçede artık her ay için bir çiçek var

Bahçedeki bir saksıya tıklayınca o ayın çiçeği bütün ekranı kaplıyor —
her biri kendi rengi, kendi yaprağı ve kendi küçük yükleme ekranıyla.

| Ay | Çiçek |
|---|---|
| Ocak | Kardelen |
| Şubat | Menekşe |
| Mart | Yasemin |
| Nisan | Lale |
| Mayıs | Şakayık |
| Haziran | Gül |
| Temmuz | Zambak |
| Ağustos | Ayçiçeği & Papatya |
| Eylül | Leylak |
| Ekim | Karanfil |
| Kasım | Kasımpatı |
| Aralık | Kokina |

Ağustos tek çiçek değil: devasa ayçiçeklerinin arasına minik papatyalar
serpiştirilmiş bir tarla.

Bir de gizli bir on üçüncü ay var — başlığın yanındaki soluk ✦ işaretine
tıklayınca açılıyor.

Çiçeklerin hiçbiri hazır görsel değil; hepsi kodun içinde SVG olarak
çiziliyor ve her açılışta aynı şekilde yerleşsin diye sabit bir rastgelelikle
dağıtılıyor.

### Çalıştırmak için

```bash
cd frontend
npm install
npm run dev
```
